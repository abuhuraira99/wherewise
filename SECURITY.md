# Security

Wherewise processes uploaded files only inside the visitor's browser. Nothing a user uploads is sent to a server.

If you find a security problem, please open a private security advisory on GitHub (Security tab, "Report a vulnerability") rather than a public issue. Include steps to reproduce and the browser you used. I aim to reply within a week.

In scope: the web app, the `/api` worker and the expression language sandbox. Out of scope: the third-party basemap tiles and the public data sources.
